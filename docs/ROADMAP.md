## 0. 一句话定位
不是"树洞(Tree Hole)",而是一个**"让情绪漂流、让善意找到它们的地方"** —— 由星空 / 音乐 / 气球 / 海浪组成的**情绪空间**。核心力量感:*"我把它放出去,希望有陌生人接住它。"*

**现阶段首要目标不是赚钱**,而是证明"这个世界真的会有人回来"——关注**留存、回访、真实的安慰感**。

---

## 1. 品牌与理念
- 坚持品牌名 **ARE YOU ALRIGHT?**(关怀感、情绪张力、记忆点;不限制未来:悲伤 / 希望 / 感谢都能容纳)。
- 从"消费内容看完就走"→"创造一个可回访的情绪空间 / 体验"。
- 打赏文案:`Buy me a coffee` → **`Keep this sky glowing`**。

## 2. 情绪交互机制(产品的灵魂)

### ①+④ 气球"飘带"= 陌生人停留 / 陪伴式提示 ⭐(用户核心想法)
每个飘动的气球**下方挂一条小飘带**,文字随该气球的**回复数(warmth)**变化,每个气球内容不同、随风飘动:
- **0 条回复**:`还没有人回复,来接住 TA 吧 →`(邀请陌生人点开回复)
- **≥1 条**:`已经有 N 个人为 TA 停留` / `有陌生人回复了 TA`
- 语气是"陪伴感"而非"评论数"。避免冷冰冰的"58 条评论"。
- **实现**:`warmth`(=非隐藏回复数)已随 `/api/bubbles` 列表返回,`scene.js` 渲染气球时即可读取——**无需改后端**。飘带是 `.lantern` 下方的一个 DOM 元素 + CSS。

### ② 传递微光 Passing Light
- 气球旁一个"**留一点光**"按钮:无需留言,点一下气球多一点柔光。
- **不显示点赞数 / 不排名**;随光点累积,气球慢慢变亮 → 轻盈、安静的陪伴。
- **实现**:后端加 `lights` 计数字段 + 一个自增接口(带简单防刷);前端把光晕强度 `--glow` 与 `lights` 挂钩。

### ③ 气球随回复"成长"(视觉隐喻)
不是单纯变大,而是**光影叠加 + 颜色渐变**:
- 光影:`初始` → `1 条:一个小光点` → `5 条:几只慢飞萤火虫` → `大量:柔和星光环绕`。
- 颜色(治愈隐喻):`淡蓝(初始/忧郁)` → `月白` → `暖金(被治愈)`。
- **实现**:纯前端,按 `warmth`(+ `lights`)分档切换特效与配色。

### ⑤ 首页每日暖句
- 首页飘一句**每天变化**的温暖话语(如 *"You don't have to carry everything alone"*),免登录即有新鲜感与慰藉。
- **实现**:一组句子,按日期取一句,纯前端。

### (附)发布 / 评论界面重设计 —— 用户当前最在意
现有底部小弹窗体验局促。目标:像成熟平台的评论体验。
- **回复**:气球阅读页底部**常驻输入栏**,点开顺滑展开;输入框上方一句**温柔引导**("如果这是你的朋友,你会怎么说?");发送键醒目;署名选填收起。
- **发布**:干净大输入区、舒服行距、情绪类型(倾诉 / 许愿)清楚切换、字数提示低调、顶部一句引导语。
- 气质:更大留白、更柔动效,契合"情绪空间"。

## 3. 善意守护 Kindness Guard(审核)
**核心原则:允许痛苦,禁止伤害(Pain is welcome. Harm is not.)**——疗愈平台,不是纯言论自由平台。
- **对表达宽容**:思念 / 失恋 / 孤独 / 绝望 / 后悔等负面情绪都接纳(那是在表达自己)。
- **对伤害零容忍**:针对他人的辱骂 / 人身攻击 / 嘲笑 / 霸凌 / 歧视 / 诅咒 / 骚扰,严拦。

机制(四层):
1. **敏感词过滤**(已部分实现:辱骂 / 联系方式 / 危机词 `src/filters.js`)。
2. **AI 语义识别**:识别"没脏话但有攻击/嘲讽/霸凌"的内容 →(需接 AI 服务,见开放问题)。
3. **发送前温柔提醒**(不直接拦):`这里是一个以善意为原则的空间,你愿意换一种表达方式吗?`
4. **人工复核**:涉及生死 / 违法 / 举报。
- **命名**:对外叫 **Kindness Guard(善意守护)**,不叫"内容审核"。
- **交互温柔引导**:回复框上方提示"一句真诚的话,可能会陪伴一个陌生人很久"。
- **《社区原则》页** + 首页善意声明。
- 护城河:一种"永远善意、没有攻击"的回复文化——最难被抄。

## 4. SEO 与隐私:公开品牌 + 私密内容
架构分"前面的世界(公开)"与"后面的世界(私密)"。
- **可收录(只服务官方页)**:首页 / About / FAQ / Help / Blog。
- **禁止收录(用户内容)**:所有 UGC 加 `<meta name="robots" content="noindex,nofollow">`,`robots.txt` 精准 `Disallow` 用户路径,`sitemap` 只放官方页。
- **首页信任承诺**:*"Your stories remain private and are not indexed by search engines."*
- 版权:每个故事归作者,默认**禁止他人转载**;仅提供**作者一键分享**(已做:分享=链接、录像仅本人)。
- ⚠️ **结构前提**:当前整站是单页 App(只有 `/`),没有 About/Blog 等独立页面。本模块本质是**新建一套官方页面体系**,属子工程 → 放到三期。

## 5. 商业模式(后期,不打扰用户)
保持"干净"氛围,不过早上广告 / 付费墙。梯度盈利:
1. 支持性打赏:**Keep this sky glowing**。
2. **永久气球 Forever Balloon**:付费让思念长留星空。
3. **点亮微光 Leave a Light**:付费支持社区、点亮他人气球。
4. **纪念册 Memory Book(核心收入)**:把用户故事 + 陌生人回应 + 视觉背景整合成 PDF / 实体书(纪念逝者 / 爱情 / 人生记录的强动机)。
5. 公益赞助:心理健康类组织的页脚赞助。

## 6. 传播 / 增长
- **短视频 TikTok/Shorts**:主要获客,让人初步认识产品。
- **官方博客(SEO 长期流量)**——只写用户会搜的痛点,不写产品新闻:
  - 痛点解答:《如何走出失恋》《如何面对失去亲人的悲伤》《为什么向陌生人倾诉更容易》…
  - 原创专栏 **Letters to the Sky(写给天空的信)**:《写给那个一直没说再见的人》《如果今晚很难熬,希望这封信能陪陪你》…
  - **Weekly Reflection(每周微光)**:不涉隐私地总结一周社区情绪。
  - 文末放 `Visit the Sky` 引导按钮,不展示具体用户故事。
- 分享规则:默认禁止他人转载,只给作者一键分享(保护隐私 + 兼顾传播)。

## 7. 分期开发顺序(已与用户确认)

- **一期 · 情绪核心(投入小、见效大)** ⭐ 先做
  - 发布 / 评论界面重设计
  - 气球**飘带**(陌生人停留 / 陪伴提示,含"还没回复→邀请")
  - 首页每日暖句
  - 打赏改名 `Keep this sky glowing`
  - 《社区原则》页 + 首页隐私/善意一句话承诺
- **二期 · 视觉成长 + 轻审核**
  - 传递微光 Passing Light(后端 `lights` 字段 + 接口 + 光晕)
  - 气球随回复成长(光效 + 颜色渐变)
  - 发送前"温柔提醒"
- **三期 · AI 审核 + SEO 体系**
  - AI 语义识别 + 温柔引导
  - 官方页面(About/FAQ/Blog)+ noindex/robots/sitemap + 隐私承诺
- **四期 · 商业化**
  - 纪念册 PDF → 永久气球 / 点亮微光等付费

每期做完由用户验收再进下一期。
